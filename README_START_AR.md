# فيديو التعريف بخدمات عبدالله الوحيشي على Upwork — حزمة الإنتاج

هذه الحزمة جاهزة للتنفيذ من **هاتف أندرويد** عبر مستودع GitHub جديد وCodex Cloud. لا يلزم كمبيوتر أو تثبيت محلي.

## ما تحتويه الحزمة
- `public/presenter_cropped.mp4`: الفيديو المصوّر، بطوله الأصلي مع إزالة الشرائط السوداء فقط. يظل بخلفية كروما خضراء؛ لم يتم عزله مسبقًا.
- `PRODUCTION/VOICE_SCRIPT_EN.txt`: النص الإنجليزي المطابق لما قيل في الفيديو.
- `PRODUCTION/STORYBOARD_AR.md`: المشاهد وعناصر الموشن المقترحة والتوقيتات التقريبية.
- `PRODUCTION/DESIGN_SYSTEM.md`: نظام الألوان والتكوين والحركة.
- `PRODUCTION/AUDIO_TIMING.json`: نقاط التوقف/المراسي المبدئية؛ يجب على Codex مطابقتها مع الصوت قبل البناء.
- `PRODUCTION/ASSET_MANIFEST.json`: المسارات الحقيقية لتصاميم الحالمي وأبو شعيب وOSHENZ في مستودع البورتفوليو.
- `scripts/stage_assets.sh`: نسخ تصاميم العملاء المطلوبة من مستودع البورتفوليو أو موقعه المنشور؛ يتوقف بوضوح إذا فشل بدل وضع صور وهمية.
- `scripts/key_presenter.py`: طريقة بديلة مجرّبة لعزل الخلفية ذات اللون التركوازي باستخدام HSV، وإنتاج فيديو WebM بشفافية لإدخاله في Remotion.
- `reference/`: صور مرجعية من التصوير للمراجعة البصرية.
- `CODEX_TASK.md`: المواصفات والمعايير التي ينبغي على Codex تنفيذها.
- `CODEX_PROMPT.txt`: أمر قصير واحد يقرأه Codex وينفذ العمل.
- `work_log/STATUS.md`: مكان حفظ التقدم عند توقف حد استخدام Codex.

## الخطوة الأولى من الجوال
أنشئ مستودعًا جديدًا **خاصًا** على GitHub باسم `upwork-intro-motion` ثم ارفع إليه ملف ZIP الموجود في هذه المحادثة كما هو (بدون فك الضغط على الجوال). يمكنك إضافة README عند إنشاء المستودع لتفعيل رفع الملفات من المتصفح.

بعد إنشاء المستودع ورفع الملف، افتحه في Codex Cloud وأرسل له نص `CODEX_PROMPT.txt` الموجود أيضًا أدناه إن أردت. سيقوم Codex بفك الضغط واستخراج المرفقات.

**مهم:** تصاميم العملاء ليست مضمنة في ZIP لتسهيل رفع الحزمة من الهاتف (أقل من حد 25MB للملف الفردي). مساراتها الدقيقة متحقَّق منها في GitHub وستُنسخ عبر `scripts/stage_assets.sh`. إذا لم يُسمح لـCodex بالوصول إلى مستودع البورتفوليو الخاص، سيحاول موقع البورتفوليو المنشور، وإلا سيتوقف ويطلب تفعيل الوصول. لا تستخدم صورًا بديلة عامة.
